# 复现《面向具身智能机器人的快速精准抓取位姿估计》Demo可执行清单
> 重要说明：该论文**无官方开源代码**，该论文算法骨架基于 GraspNet‑Baseline / GSNet 代码范式改造。我们以**GraspNet‑1Billion数据集生态作为基线底座**，复现它核心链路：RGB‑D输入 → 2D抓取区域热图预测 → 局部点云截取 → 非均匀采样抓取搜索；VLM语言交互部分做最简接入。
> 目标：先跑通仿真数据集Demo（优先，不需要实物机械臂），后续再迁移真实相机；你的力学优化模块暂时不加入，先复现基线。

## 五\(\gamma、\beta\)分步可执行实现步骤（Step by Step Demo）
> 阶段1：数据读取与预处理；阶段2：复现网络前半部分2D抓取区域预测；阶段3：二维到三维点云映射\(\gamma、\beta\)特征融合；阶段4：非均匀抓取位姿搜索；阶段5：VLM语言交互demo；阶段6：可视化+评估；阶段7【可选】迁移真实相机实物。

### Step 1：环境&数据集校验（先跑通，不训练网络）
1. 激活conda环境，设置数据集环境变量；
2. 运行graspnet‑baseline自带demo脚本，确认可以读取场景，depth转点云\(\gamma、\beta\)可视化点云\(\gamma、\beta\)读取抓取标签。
```bash
cd graspnet-baseline
python demo/graspnet_demo.py
```
✅预期结果：弹出窗口，显示场景点云+真值抓取位姿；说明数据集\(\gamma、\beta\)Open3D\(\gamma、\beta\)graspnetAPI全部正常。

### Step2：搭建论文网络第一部分：编码‑解码抓取区域预测模块
1. 下载HRNet预训练权重（HRNet‑W32）作为骨干；
2. 搭建解码头（上采样层），输出4路热图：
   - $Q_c$抓取区域置信热图
   - $Q_\theta$旋转角度热图
   - $Q_w$夹爪宽度热图
   - $Q_d$深度偏移热图
3. 实现论文损失函数：$L = L_c+aL_\theta+bL_w+cL_D+L_v+dL_o$
4. 数据集读取：读取RGB‑D图像，做论文预处理：图像resize到640×360；实现**高斯编码对抓取中心点标签编码，网格锚框标签生成**。

> 测试：输入一张GraspNet的RGB‑D，网络输出热图，可视化热图看高置信抓取区域是否落在物体上。

### Step3：二维抓取区域映射三维点云，局部球形区域+特征融合
1. 从热图选出top‑$k_c$高置信网格；
2. 根据相机内参，将图像坐标$\((u,v)\)$ +深度d，投影三维$\((X,Y,Z)\)$；
3. 以三维点为球心，球半径为预测的夹爪宽度w，截取球形局部点云；做最远点下采样得到N0=512点；
4. **实现语义‑点特征融合模块**：将RGB图像纹理特征与PointNet点云几何特征拼接池化，输出局部融合特征$F_{local}$。

✅输出：每一个候选抓取区域得到一块局部点云 + 融合特征。

### Step4：实现【非均匀采样抓取位姿搜索算法】（本论文最大创新模块）
> 原基线GraspNet/GSNet用球面均匀采样，这里替换成本文块坐标下降迭代优化接近向量。
1. 训练阶段：实现块坐标下降迭代公式，交替更新独热编码矩阵$B_\alpha$和预测角度$\alpha$；优化接近向量分布；
2. 推理阶段：输入局部融合特征$F_{local}$，MLP做分类，输出非均匀分布的接近向量，对应$\gamma\(\gamma、\beta\)\beta$；
3. 拼接已经预测好的$u,v,\theta,w,d$，组装完整6‑DoF抓取位姿 $g=\{u, v, \theta, w, d, \gamma, \beta\}$。

> 测试：输入局部点云，输出一批6‑DoF抓取位姿；Open3D可视化夹爪，看候选姿态是否生成。

### Step5：VLM语言交互最简Demo（可选，具身交互部分）
> 不需要微调Qwen‑VL，推理即可；模拟用户指令“抓取毛绒玩具”
1. 加载Qwen‑VL预训练模型；
2. 输入prompt：`"框出图中的毛绒玩具"`，输入RGB图像，输出2D bounding‑box；
3. 在网络输出的全部抓取候选中，筛选中心点落在bbox内的抓取，取置信度最高作为最终抓取位姿。

### Step6：可视化+评估
1. 可视化：Open3D绘制场景点云 + 预测6‑DoF抓取夹爪；复现论文图3可视化效果；
2. 复用graspnet‑baseline的`eval.py`评估脚本，计算 $AP\(\gamma、\beta\)AP_{0.8}\(\gamma、\beta\)AP_{0.4}$；
3. 对比基线GraspNet\(\gamma、\beta\)GSNet的指标。

### Step7【可选，实物迁移，后期做】
1. RealSense D435i采集RGB‑D，对齐彩色与深度；
2. 图像resize到640×360送入网络；输出6‑DoF抓取位姿；相机坐标系转到机械臂基坐标系；
3. UR3接收位姿，执行抓取。

## 六\(\gamma、\beta\)遇到的坑提前提示
1. ❗GraspNet数据集相机有RealSense/Kinect两套，论文只用RealSense，不要混用。
2. ❗HRNet输入输出分辨率，网格划分参数：$r=8, k_a=6$，严格和论文超参对齐。
3. ❗非均匀采样训练阶段块坐标下降迭代是**训练时更新接近向量**，推理阶段直接用训练好的向量，推理不迭代，这点非常容易写错。
4. ❗RGB‑D和点云坐标系对齐，像素投影公式出错会导致抓取点飘离物体。
